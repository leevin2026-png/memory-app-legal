为什么照片没有全部显示？

请前往 iOS“设置”→“隐私与安全性”→“照片”→“Memory”，确认已选择“完全访问”，或在“有限访问”中补充需要显示的照片。权限更改后重新打开 Memory。

为什么足迹没有地点？

Memory 只读取照片本身已有的位置元数据，不请求实时定位。截图、社交应用保存的图片或关闭定位后拍摄的照片可能没有位置信息，因此不会出现在足迹中。

照片会上传吗？

不会上传到 Memory 开发者服务器。照片整理、相册记录和缓存主要保存在设备上。地图与城市名称可能由 Apple 地图和地理编码服务处理，详情见隐私政策。

清除缓存会删除照片吗？

不会。图片缓存用于加快浏览，清除缓存不会删除系统照片库中的原始照片。之后再次浏览时，Memory 会按需重新生成缓存。

如何删除应用内数据？

可在 Memory 中删除自行创建的相册和文件夹，并在设置中清除图片缓存。卸载 Memory 会删除应用沙盒中的设置、整理记录和缓存，但不会自动删除系统照片库中的照片。

Why are some photos missing?

Open iOS Settings → Privacy & Security → Photos → Memory. Choose Full Access or add the missing photos to Limited Access, then reopen Memory.

Why is the footprint empty?

Memory reads location metadata already embedded in photos and does not request live device location. Screenshots, images saved from some apps, or photos captured without location metadata may not appear.

Are photos uploaded?

Photos are not uploaded to a server operated by the Memory developer. Organization records and cache are primarily stored on your device. Apple map and geocoding services may process coordinates to display maps and place names. See the Privacy Policy.

Does clearing cache delete photos?

No. Cache files improve browsing speed. Clearing them does not delete original items from the system Photos library; Memory recreates cache files when needed.

How do I remove app data?

Delete Memory albums and folders in the app and clear image cache in Settings. Uninstalling Memory removes settings, organization records, and cache stored in its app sandbox, but does not automatically delete photos from the system library.
